# 🐾 PawSOS – Animal Emergency & Rescue Network

**Every Second Matters. Every Animal Deserves Care.**

PawSOS is a web-based animal emergency rescue platform designed to connect citizens with rescuers, veterinary professionals, NGOs, and animal shelters.

### 🎯 Problem Statement
Injured and sick street animals often face delayed assistance due to poor communication, unavailable rescuers, and a lack of coordinated emergency services.

### 💡 Our Solution
PawSOS provides a centralized platform where citizens can report animal emergencies by uploading photographs, sharing GPS locations, and describing the situation. The system supports rescue coordination, verified responder assignments, veterinary assistance, and rescue status tracking.

### ✨ Key Features
- Emergency SOS Reporting
- GPS-Based Location Sharing
- Rescuer Registration and Verification
- Rescue Assignment and Tracking
- Veterinary Treatment Management
- Citizen, Rescuer, Veterinary, NGO and Admin Dashboards

### 💻 Technology Stack
**Frontend:** React, TypeScript, Tailwind CSS

**Backend:** Node.js, Express.js

**Maps:** Leaflet

**Development Tools:** VS Code, GitHub

### 🚀 Project Status
Functional prototype with emergency reporting, role-based dashboards, and rescue coordination workflows. Production database integration and public deployment are planned.

### 🌍 Our Vision
To build a faster, more accessible, and transparent animal rescue network where every animal in distress has a better chance of receiving timely assistance.

**One Report. One Response. One Animal Closer to Care.**
